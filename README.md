## 源码快照说明

- 是**开发机 `E:\开发项目\GrayDesk2.0` 的文本源码只读快照**，不是 git 子模块，也不是可直接编译的完整工程。
- 排除了 22 个二进制/大文件：PP-OCR ONNX 模型（16MB）、壁纸 gif/png、exe/dll、构建产物（bin/obj/dist）。
  完整清单见 `src/_excluded-files.txt`。要构建请到开发机取二进制资源，或直接用发布包。
- 源码内的 `192.168.1.88`、`123456789`、`Ab1234` 等是**单元测试假数据**，不是真实内网地址或客户信息。
- 源码内自带的 `src/README.md` 是旧版（仍写 2.2.0 / GrayDeskV2），已在测试报告中列为待修项；
  **以本页和 HANDOFF 为准**。

## 脱敏声明

本仓库为公开仓库，已做脱敏：

- 内网 IP、真实手机号、真实识别码、真实客户姓名 → 占位符
- 含真实屏幕数据的探针截图 / OCR 抓取结果 → 由 `.gitignore` 排除，未入库
- 真机界面截图 → 仅保留布局，识别码数字已打码

如发现残留敏感信息，请告知开发侧处理。
